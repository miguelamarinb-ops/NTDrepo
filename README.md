Tarea Nuevas tecnologías de desarrollo Miguel Angel Marin Baracaldo 506242017.

Este proyecto fue desarrollado como parte de la materia de Nuevas Tecnologías de Desarrollo, utilizando diferentes herramientas y tecnologías para crear una aplicación web funcional.

La aplicación consiste en un gestor de tareas desarrollado bajo el patrón de arquitectura Modelo-Vista-Controlador (MVC), utilizando Python y Flask. El proyecto permite gestionar tareas mediante una interfaz web sencilla y organizada.

Tecnologías utilizadas
- Python
- Flask
- HTML
Clonar el repositorio
git clone https://github.com/miguelamarinb-ops/NTDrepo

Entrar el proyecto cd NTDrepo

Crear el entorno virtual

python -m venv .venv
Activar el entorno virtual

.venv\Scripts\activate

Instalar librerías
pip install -r requirements.txt

Para ejecutar la aplicación Flask
python app.py

Después, abrir en el navegador:

http://127.0.0.1:5000
